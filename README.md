# Modern JavaScript Practice - Day 3

This repository contains practical examples and core concepts completed during **Day 3** of the JavaScript practice.

## 📌 Topics Covered
- **Scope**: Global, Function, and Block Scopes (`var`, `let`, `const`).
- **Hoisting**: Variable and function hoisting behavior.
- **Closures**: Functions retaining access to their lexical environment.
- **`this` Keyword**: Execution context in standard functions and objects.
